# lazycloud

A terminal UI for various cloud provider CLIs.

## Installation

### Cargo (from source)

```sh
cargo install lazycloud
```

### Homebrew (macOS/Linux)

```sh
brew install jorgeparavicini/tap/lazycloud
```

### Scoop (Windows)

```sh
scoop bucket add lazycloud https://github.com/jorgeparavicini/scoop-bucket
scoop install lazycloud
```

### Shell installer (macOS/Linux)

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/jorgeparavicini/lazycloud/releases/latest/download/lazycloud-installer.sh | sh
```

### PowerShell installer (Windows)

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://github.com/jorgeparavicini/lazycloud/releases/latest/download/lazycloud-installer.ps1 | iex"
```

### Pre-built binaries

Download pre-built binaries from the [GitHub Releases](https://github.com/jorgeparavicini/lazycloud/releases) page.

## Usage

```sh
lazycloud
```
